🎮 اللعب

🔊 القراءة الصوتية

عند تفعيل القراءة يبدأ مؤقت الإجابة بعد انتهاء قراءة السؤال. زر 🔊 بجانب السؤال يعيد القراءة.

☁️ صوت Azure (اختياري)

بدون مفتاح تُقرأ الأسئلة بصوت المتصفح. مع مفتاح Azure Speech يصير الصوت أوضح وأقرب للطبيعي.

🔒 المفتاح يُحفظ على هذا الجهاز فقط: لا يدخل الكود المنشور ولا ملف «تصدير كل البيانات». المنطقة تجدها في Azure بجانب المفتاح (Keys and Endpoint).

🎤 الأوامر الصوتية

للدوران: Spin the wheel • Turn the wheel • Rotate the wheel • Roll the wheel • Start spinning • Spin it • Let's start (في بداية الحصة فقط).

لتأكيد الإجابة الصحيحة: Correct! • Excellent! • Well done! • Great job! • Brilliant! • That's right! • Perfect! • Amazing! • Fantastic! • Absolutely!

يعمل على Chrome وSafari ويحتاج إنترنت وإذن الميكروفون. لا تُحفظ تسجيلات الصوت.
